# Project overview

Forge Studio currently provides a private personal resume workspace: Google sign-in, a saved resume library, reviewed file upload, rich section editing, immutable versions, readiness/JD matching, scoped paid-Gemini rewrites, three saved template styles and owner-only PDF downloads. The master profile is optional; uploads do not silently populate it.

The first JD-to-application slice is approved and connected: understand a job, compare saved facts, review tailored proposals and export a separate copy. Personal tracking, cover-letter/message drafts and monetization follow later. [PLAN.md](../PLAN.md) distinguishes delivered scope from planned phases.

Personal application tracking is distinct from employer hiring software. The new plan expands the earlier blanket exclusion of personal job tracking, billing and cover letters only as proposed future scope. It does not promise offers, activate organization/vendor collaboration or authorize automatic outreach.

Preserve Individual, Organization and Vendor models, separate professional/contact data, actor/workspace/resource checks, immutable versions and reviewed AI application. Missing qualifications remain gaps; every generated claim requires support. Resume edits and tailored copies never change the master profile without an explicit separate merge.

Use [implementation audit](../docs/implementation-audit.md) for current source evidence, [progress](progress-tracker.md) for work status and [setup](../README.md) for commands. Historical phases are no longer the execution roadmap.

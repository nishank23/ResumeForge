## What works now

The approved professional white/Georgia resume remains the main surface. Header and separate synthetic contacts, non-Skills headings and entry text/achievements edit directly on the paper. Summary and entry descriptions use the shared constrained Tiptap adapter. Other sections reveal their selected target's contextual actions outside the paper; entries/achievements have item arrows and Summary has none. Skills now groups the five default categories and spoken Languages, and opens a full category/tag dialog on click or Enter/Space. Skills has no floating AI/action bar or direct inline fields. Whole-section ordering and compact navigation/add controls remain outside the paper. Extra paragraph/bullet/skill-row margins are removed; actual line breaks remain.

Edit opens a scrolling shared dialog with labeled fields and fixed Save/Cancel footer. Header, Experience, Education, Projects, categorized Skills and Languages have local forms. Optional dates support month/year, current and year-only flags; invalid ranges cannot save. Optional grades have no invented default; links permit HTTP(S) without embedded credentials. Dialog candidates preview immediately, Save changes only the target in one workspace transaction, and dirty Cancel/Close/Escape offers Keep editing/Discard. Provisional new entries disappear on discard. Dialog Undo/Redo stays isolated until Save. Focus returns to the selected Edit action or its section fallback.

Every relevant dialog offers **Auto-fill sample details**, filling only empty target fields with clearly fictional examples. Typed values and stable IDs are retained; Undo/Cancel reverses the examples. Hide retains content but excludes it from Preview; Delete confirms the exact target and local Undo restores it. Guarded moves beyond first/last/single-item boundaries show an accessible error without changing draft/history. Missing sections can be added empty. Workspace Save locally checkpoints the entire draft; Cancel restores it, and all edits/order/visibility share up to 100 history snapshots.

## Boundaries

All initial names, contacts, qualifications, metrics, technologies and languages are synthetic demonstration data. The typed local draft is separate from service DTOs and keeps demo contacts out of professional sections/AI targets. Nothing loads real contacts, writes profile/resume APIs, persists to browser storage or changes authentication/authorization. Reload, leaving the editor, route/session loss resets the draft/checkpoint/history.

Real blank/profile creation, protected contact load/save under D12, durable versions/conflicts/recovery, grounded AI, ATS rules/evaluation/issue lifecycle, PDF/pagination and F20 remain pending. Improve with AI explains the missing provider/version/evidence prerequisites; ATS says **Not evaluated**; Export PDF is disabled. These controls do not claim scoring, generation or export.

1. Click a name, headline, contact-demo field, heading, entry title, achievement on the paper and type. Enter or blur applies it; Escape restores the active field and focuses Edit. Summary/descriptions update immediately. Confirm unrelated fields remain unchanged. Dates/links use Edit; Alt Enter opens details.
2. Hover/click/focus an Experience entry: check AI, Up/Down, Edit, Hide and Delete. Select Summary: item arrows are absent. An impossible first/last/single-item move shows an error with no dirty/history change. Move two entries or bullets within their own list, then Undo/Redo.
3. Open Edit, change fields, Save, then Undo once to restore the entire edit. Use Tab/Shift Tab to verify trapping, and Escape with a dirty form to Keep editing/Discard. Cancel a provisional new entry and confirm it disappears.
4. Add Experience/Education/Project entries. Type one field, then Auto-fill sample details: it stays unchanged while empty fields receive fictional examples. Undo/Redo and Cancel remove/restore the examples. Test an end date before start; current clears/disables end dates. Test an unsafe link: Save shows a field error.
5. Click Skills or focus it and press Enter/Space. Add/remove/edit tags in all five groups and Languages, with optional proficiency; create/rename/reorder/delete a category, verify confirmation and dialog Undo/Redo, Save and Cancel. No Skills toolbar should appear. Hide content and switch Preview: it disappears and no editable fields/actions appear on paper. Delete an exact item/section, confirm, then Undo; add a missing empty section.
6. Save locally, edit multiple fields/order/visibility, then Cancel. Confirm the checkpoint returns. Cmd/Ctrl S saves; Cmd/Ctrl Z/Shift Z or Ctrl Y changes history outside plain text fields. Plain fields retain native typing undo until blur. Dialog shortcuts use its isolated history. Reload restores the original synthetic sample.
7. At 390px and 320px, click a non-Skills paper target and use the fixed contextual bar; Skills should open its dialog instead. These widths require manual re-verification for the new Skills dialog. Scroll dialog fields while its Save/Cancel footer remains reachable. Try long Unicode text/unbroken words, Preview and scrolling through Languages. The paper grows without horizontal overflow.

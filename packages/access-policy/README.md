# `@resume-forge/access-policy`

Server-side policy primitives shared by REST, jobs, downloads, and MCP.

The current Phase 1 slice establishes only personal workspace and resource
ownership. It exports the approved 27-name permission vocabulary without role
bundles, because D05 is still open. Organization/vendor membership, field
projection, durable auditing, and persistence adapters are added only after
their dependent decisions and database contracts are settled.
